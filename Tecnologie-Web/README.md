## Programma ufficiale ed esame (scheda del corso, a.a. 2026/27)

Fonte: la scheda del corso linkata da Moodle (`laurea.informatica.unito.it`, Tecnologie Web MFN0634, 3° anno, primo semestre, 6 CFU: 24 ore di teoria e 30 di laboratorio, docenti Noemi Mauro e Angelo Geninatti Cossatin). Il programma è: architettura delle applicazioni web, JavaScript e TypeScript (con Node e npm); front-end con HTML, CSS, DOM API, fetch e Promise API, pattern MVVM, Single Page Application e **React**; back-end con anatomia di un server HTTP, programmazione server-side in **Java con Spring**, **Java Persistence API**, sessioni e credenziali, e costruzione dell'applicazione completa. L'esame è uno **scritto di teoria** (domande a risposta chiusa e aperta, in trentesimi; durata non indicata) più un **progetto con discussione** (una single page application con front-end TypeScript+React e back-end Java+Spring, individuale o in coppia, in trentesimi); il voto finale è la media dei due. La pagina in inglese indica minimo 18 e lode se tutte le risposte aperte hanno il punteggio massimo; la pagina italiana non lo riporta. Non è indicato nessun libro di testo, solo risorse online (react.dev, manuale TypeScript, MDN, tutorial di Spring Boot).
